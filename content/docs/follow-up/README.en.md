# Follow-up Source Index

**Coverage checked through 26 November 2026 (HKT).** This index links to public records and reporting on the inquiry, prosecutions, housing and residents' lives. It provides short summaries without reproducing news articles.

**Collection date and method**: Every source below was collected from official public records or by web consultation on 26 November 2026 (HKT). Table dates identify publication dates; continuously updated service pages are marked separately. This batch indexes sources without downloading external reports or news articles for local preservation. Some official sources are in Chinese.
