# 義工及社區支援資訊

[English](README.en.md)

**現行支援資料截至：2026年11月26日（HKT）。** 下方另保留2025年11月28日的災初社區資源紀錄。

## 現行長遠安置與援助

- **官方入口**：[大埔宏福苑支援服務](https://www.taipofire.gov.hk/chi/index.html)、[經濟援助及「一戶一社工」](https://www.taipofire.gov.hk/chi/financial.html)、[房屋局長遠居住安排](https://www.hb.gov.hk/wfc/tc/long-term/index.html)及[特設銷售計劃](https://www.hb.gov.hk/wfc/tc/special-sales-exercise/index.html)。
- **收購與選樓進度**：黃偉綸於2026年11月26日在香港電台表示，1,914戶已簽署具約束力的《買賣協議》，1,730多戶完成業權轉讓；另有57戶希望出售、尚待確認業權及完成法律程序，13戶暫不出售。簽約、轉讓、選樓及入住屬不同階段。[當日訪問報道](https://news.rthk.hk/rthk/ch/component/k2/1879328-20261126.htm)
- **租金補助**：2026年7月17日公布的安排，讓業主不論選擇現金收購、特設銷售或「樓換樓」，均可領取補助至2027年12月21日；每年15萬元，每半年發放75,000元。特設銷售單位在該日之後交付者，可按公布條件延至購入新單位的轉讓契據日期起三個月。[官方安排](https://www.info.gov.hk/gia/general/202607/17/P2026071700328.htm)
- **新生活支援補助（已公布，待發放）**：2026年11月24日宣布每戶單位業主合共30萬元，分2026年12月底、2027年6月底各發15萬元；家屬就每名罹難者獲20萬元，2026年12月底起一次發放。已出售業權予政府的原業主亦適用。兩項補助透過「一戶一社工」發放，毋須另行申請。[官方公告](https://www.info.gov.hk/gia/general/202611/24/P2026112400134p.htm)

## 情緒與持續支援

「一戶一社工」可協助居民取得情緒支援、心理輔導及經濟援助轉介。麥美娟於2026年11月26日表示，「守望．同行」及「凝聚．同行」計劃會繼續提供支援；居民可透過所屬社工聯繫服務。[官方服務介紹](https://www.taipofire.gov.hk/chi/financial.html)、[當日訪問報道](https://news.rthk.hk/rthk/ch/component/k2/1879328-20261126.htm)

更多有日期的公告及居民報道，見[災後跟進來源索引](../docs/follow-up/README.md)。以上來源於2026年11月26日（HKT）以網上查閱方式收集；個別服務安排以相關機構最新公告為準。

### 2.4 大埔火警危機支援 - 社區資源管理

- **網址**：<https://supporttaipohk.com/>
- **核心功能**：
  - **上傳資源**：市民可上報支援資訊，由AI初步整合
  - **義工定位**：使用GPS追蹤當值義工位置（無人力調度功能）

  - **需求與提供區**：居民可留言回應，尋求或提供協助
- **特點**：社區驅動的資源管理，強調信息驗證
